LAW 01

一切皆纸

系统里没有弹窗、抽屉、浮层——只有折叠、展开、别上、贴住、收进。每个组件都必须回答：它是哪种纸，此刻处于纸的哪种状态。

LAW 02

墨分两色

印刷黑墨 = 系统给出的内容；蓝色手写墨水 = 用户说过的话、系统记住的偏好。记忆被复用时以蓝墨呈现——"它记得我"这件事变得肉眼可见。

LAW 03

动效即物理

纸有重量。出场 = 落在桌上；确认 = 盖章；收纳 = 合拢；联动 = 从一张纸传递到另一张纸。禁止凭空淡入淡出，所有 motion 必须能被一句物理动作描述。

Tokens as Code

DTCG (W3C draft) + GSAP
tokens.json · DTCG 摘录 
{
  "color": {
    "paper": {
      "manila": { "$value": "#E9CD9B", "$type": "color" },
      "cream":  { "$value": "#F4EEDF", "$type": "color" }
    },
    "ink": {
      "blue":   { "$value": "#2E4A9E", "$type": "color",
                  "$description": "用户输入/系统记忆专用" }
    }
  },
  "motion": {
    "duration": { "l": { "$value": "700ms", "$type": "duration" } },
    "easing":   { "snap": { "$value": [0.34,1.56,0.64,1],
                  "$type": "cubicBezier" } }
  }
}
motion.js · GSAP token 对象 
// 组件只允许引用 token，禁止手写魔法数
export const MU = {
  dur:  { xs:.16, s:.26, m:.45, l:.7, xl:1.05 },
  ease: {
    paper:  "power3.out",    // 纸张展开
    fold:   "power2.inOut",  // 折叠往返
    snap:   "back.out(1.6)", // 别针/图标落位
    stamp:  "power4.in",     // 盖章下压
    settle: "elastic.out(1,.55)", // 受力回稳
    pop:    "back.out(2)"    // 地图图标弹出
  },
  stagger: .06
};
