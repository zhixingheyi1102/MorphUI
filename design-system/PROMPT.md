# MorphUI 工作台组件库「复古办公文具」Design System + Motion System 需求

## 〇、一句话定位

为 **MorphUI**（对话驱动的旅行规划工作台：左侧 AI 对话，右侧 workspace 随对话动态生长组件）设计一套 **工作台组件库的 Design System + 动效 Motion System**。不是业务页面——所有视觉、纹理、动效都服务于组件本身，组件是"摆在办公桌面上的复古文具"。

## 一、产品理念（组件为什么存在）

- 在长任务里，**文字不是好的沟通载体**。我们用 UI 组件驱动交互，替代无聊的 "wall of text"——针对不同需求提供不同样式的组件，让用户更好地探索和发现（如地图组件），最后用 **File（文件）的形式帮用户沉淀成最终的一套方案**
- 要展现**整个系统的能力**：在对话过程中记住用户偏好，并在下一次交互时直接复用
- 工作台 = 一张桌面：组件由 AI 在对话中动态 create / update / remove，可拖拽换位、可关闭
- 场景为海边城市旅行规划，组件承载真实攻略内容，**必须能装下一定量的文字**
- 技术栈：HTML + CSS + JS + GSAP（动效全部 GSAP，必须真实能动）

## 二、整体交互流程（组件出场顺序与联动）

### 1. 需求澄清（Clarify）
- 用户提出诉求（如"我要去上海两日游"）→ 出 Clarify 组件，询问预算、节奏、风格等偏好
- Clarify 是最先出现的组件，**它本身不是方案**，而是在参数（Parameters）确定之后，才会生成初步方案

### 2. 方案呈现与预算交互
- 初步方案以**折叠态的组件形式**呈现，包含路线、时间安排和交通等（如手绘简图：POI 卡序列 + 交通节点）
- 文档可通过某种**主动交互机制**，主动向用户提问："要不要看一下预算如何？"
- **预算的出现方式要有意思**：起初是一个类似**便利贴的小组件，粘在文档最下方** → 用户点击展开后，变成一个**独立容器，存在于文档之外** → 用户点击确认（Accept）后，预算卡正式加入方案，变成"方案内容 + 预算卡片"的样式

### 3. 地图组件交互
- 用户主动 Query："给我地图，我想看看路线长什么样子" → 系统呈现地图组件
- 地图组件的交互设想：
  - **多天路线切换**：地图上方有小组件，切换"第一天 / 第二天 / 第三天"日程，查看某一天的完整地图
  - **可视化景点图标**：底图覆盖物是重点景点的小图标，采用**动效图标**形式
  - **鼠标悬停动效**：地图是核心交互载体。Hover 景点图标时，**鼠标指针变成一个行走的小人**（画风与系统一致）；落到景点上时小人变换动作，提示该景点可点击
  - **折叠纸展开效果**：地图组件原本像一张折叠起来的纸。点击某个景点时纸会展开：**左边依然是地图，右边展开呈现 POI 卡片**（复用方案里的景点卡样式）
  - **玩法推荐**：POI 卡下方用有意思的方式（拼贴或短文本，**最多推荐 3 个**）呈现该景点的不同玩法；展开态可折叠，点右上角折叠后只看到地图组件
  - **智能缩放（Zoom in / Zoom out）**：地图可扩展、可探索。如 Query"帮我看看景点 1 旁边是不是有一些餐厅？"→ 地图自动 Zoom in 围绕景点 1 放大、景点 1 图标放大，周边浮现吃饭小图标
    - (a) **景点和住宿图标**：根据地标性建筑**个性化**改变
    - (b) **餐饮等周边配套**：使用**统一的卡通图标**
  - **酒店探索**：Zoom in 后可点开周边酒店图标查看具体信息，信息同样以**地图的折叠展开态**呈现

### 4. 系统主动性（记住偏好 + 主动询问）
- 系统发现用户在深入查看某个景点（探索周边美食等）时，主动一点：右侧面板弹出**"闪词"式轻量提示**："看到你正在深入了解这个景点，需要帮你找个周边的酒店吗？"（要 / 不要）
- 用户点击确认 → **交互联动**：酒店图标在地图上 pop up 出来

### 5. 沉淀成 File
- 探索完成后，所有内容收纳进旅行方案 Folder，合拢成一本手册——方案沉淀完成

## 三、组件清单（6 个顶层组件 + 子组件）

### 0. Clarify 需求澄清表（流程最前置）
- 收集：同行人员、预算、偏好；旅行节奏（悠闲还是紧凑）；风格偏好（小众还是浪漫等）
- 形态 = **文件夹系统的"附属小 file"**：一张**回形针别在文件夹封面上的档案登记卡**——手写体填空线 + 勾选框，像建档时填的索引卡
- 支持动态追问（选了某项后长出后续问题）
- 填完 = "建档完成"：盖章，登记卡别到 Folder 封面上（答案成为方案的档案索引）

### 1. 旅行方案 Folder(主组件，最大最主要)
- 形态 = **带 Tab 标签页的马尼拉文件夹**，有折叠态 / 双页展开态
- 内含子组件：
  - **POI 卡（景点卡）**：时间、名称、描述、照片，索引卡/档案卡形态。**酒店、餐厅的 POI 块复用同一样式**，仅颜色和细节变化区分
  - **交通路线**：POI 卡之间的连接节点（交通方式 + 耗时），像装订线/航线虚线
- 展开态 = 双页平铺：Day1/Day2/Day3 Tab + 按天 POI 序列
- 文档可主动向用户提问（如"要不要看一下预算？"）

### 2. Budget list 预算清单
- 形态 = **真实收据**：分区（Section）逐行金额明细 + 合计，打印质感
- 三态流转：**便利贴小组件粘在文档底部 → 点击展开为独立容器 → Accept 后合入方案**

### 3. Map 地图
- 形态 = **可折叠的复古纸地图**：折叠态 / 展开态（左地图右 POI 卡），奶油底柔和路网
- 交互：多天切换、动效景点图标、行走小人光标、智能 Zoom、个性化地标图标 + 统一卡通配套图标、酒店探索（详见流程第 3 步）

### 4. 机票清单 Flight list
- 形态 = **复古票根叠成的 list**：撕边、打孔线、条码、印章，多张票可比选

### 5. Packing list 行李清单
- 形态 = **自我提示（self-reminder）便利贴**：牛皮纸头长条便签，横线 + check 栏

### 组件间的收纳关系（核心：file 系统的二层结构）
灵感图里的每张文件夹图本身就是一个系统，遵循同一构成逻辑：
- **大主体**：大文档/文件夹，拥有折叠、半开、双页展开等多种样态 —— 对应旅行方案 Folder
- **附属小 file**：围绕大主体的小组件（回形针夹的卡片、标签贴、收据、票根、便签、拍立得）—— 对应 Clarify 登记卡、Budget 收据、Flight 票根、Packing 便签、Map 折叠地图
- 附属小 file 平时可散落桌面独立使用，最终都能**收进 / 别在 / 贴在 Folder 上**，合拢成一本手册
- 展示页要演示"散落在桌面 → 收纳进文件夹合拢"的关系

### File system 设计共性（从全部灵感图/视频提炼，所有组件必须遵守）
1. **壳 + 探出的内容物**：主体永远是一个朴素的"壳"（文件夹/活页夹/文件袋），内容物从壳的边缘**探出一角**——露边暗示厚度和"可翻开"，绝不完全藏起
2. **Tab 标签 = 导航**：顶部或侧边的 Tab 标签负责分类归档（Day1/2/3、Products/Subscriptions 那种），是系统统一的导航语言
3. **铭牌标签说明身份**：封面上贴一张手写/打字的小标签（label plate），说明"这份档案是什么"——对应每个组件的标题区
4. **万物皆有固定件**：任何附属物都被**物理固定**——回形针、长尾夹、装订圈、松紧带、纸胶带、打孔线。没有悬空漂浮的元素，这是和现代 UI 最大的区别
5. **层叠错位**：叠放的纸永远不完全对齐，带轻微旋转和偏移（±1~3°），制造真实堆叠感
6. **材质分层**：壳用朴素牛皮纸/马尼拉色（低调、中性），内容物才带颜色——灰壳彩芯
7. **打字机小字 metadata**：编号、日期、档案号（No. 00090 / ARCHIVE 08 / File #02）散布在角落，是重要的复古细节语言
8. **字体层级靠切换字重与字体族而非字号爆炸**：大标题 = 寒蝉活宋 ExBold，正文 = 活宋 Regular，metadata = 小号 JMH Typewriter
9. **做旧细节**：颗粒、印章、邮戳、撕边，点缀不铺满
10. **封面克制、内页密集**：合拢态信息密度极低（一张标签 + 一个探出角），展开后才承载大量内容——组件的折叠/展开两态都要遵守这个密度反差

## 四、风格定位

### 主题：办公文具（Office / Stationery），带一点复古味
- 核心主题是**办公文具**，不是海洋风。所有组件的形态隐喻来自办公/文具：文件夹、收据、票根、纸地图、便利贴
- 复古只是"味道"：胶片颗粒、印刷质感、做旧细节，点到为止
- 交互要有**物理纸张质感**：折叠、展开、翻页、撕开

### 色彩：高明度、低饱和，与地图配色形成呼应
配色分两层：

**① 文件夹本体（壳）= 中性色，不参与呼应**
- Folder 外壳用牛皮纸 / 马尼拉纸的朴素中性色（灰调米色、淡卡其），保持"灰壳"的低调

**② 除文件夹本体之外的一切 = 从地图取色，与地图组件形成呼应**
配色锚点 = `灵感folder/地图素材/地图-最终配色灵感.jpg`（城市分析图风格）。收据、票根、便签、POI 卡、登记卡等内容物与附属小 file，以及线条/印章/勾划等"笔迹"，全部从这张地图的色板取色：

| 角色 | 色相参考（取自地图） | 用法 |
|---|---|---|
| 纸底 | 纸白 / 米白（≈ #F7F5F0） | 桌面、内页纸张底 |
| 分区色 1 | 婴儿蓝（≈ #A9D3E5） | 大面积区块、水域 |
| 分区色 2 | 薄荷/豆绿（≈ #CDE3CE，深松绿 ≈ #4E8F6E 只做点阵肌理） | 绿地、次级区块 |
| 分区色 3 | 浅粉（≈ #F5C6DE） | 区块、贴纸、高亮 |
| 分区色 4 | 珊瑚橙 / 浅杏（≈ #F0A87E） | 区块、警示性强调 |
| 分区色 5 | 淡柠檬黄（≈ #F6EDA9） | 收据、便签、票根纸色 |
| 分区色 6 | 薰衣草紫（≈ #ABA6D4） | 次级点缀 |
| 线条/结构色 | 钴蓝路线（≈ #2B4EA8）、品红虚线（≈ #D6338A）、中性灰（≈ #9C9C9C） | 路线描边、边界虚线、细线路网、文字辅助 |
| 文字主色 | 深灰蓝（近黑但不用纯黑） | 正文与标题 |

- 原则：**大面积永远是纸白底 + pastel 色块；饱和色（钴蓝、品红）只出现在线条、虚线、印章、路径描边这类"笔迹"上**，就像分析图里深色只是线和点
- 组件之间的呼应逻辑：地图上某天路线用什么色，对应那天的 POI 卡、票根、收据分区就用同色系——**色彩是跨组件的关联线索**
- 禁止：高饱和克莱因蓝大色块、现代扁平风、纯黑

### 肌理（直接借用地图的图面语言）
- **halftone 点阵 / 网点填充**（地图里的绿地点阵、粉色点群）
- 细线 hatching 排线、微型格网、虚线边界
- 纸张纹理、胶片颗粒

### 保真度
- 不要高保真；风格化、有通用性和延展性——看得出是 UI，但更像一套纸品文具

## 五、交付物（三份）

### 交付物 1：Design System 文字文档（Markdown）
1. 设计原则 / 哲学
2. 色彩体系（每个颜色分别用在哪里）
3. 间距与层级规范
4. Dos & Don'ts

### 交付物 2：HTML 组件库展示页
按分区陈列，所有视觉真实可看、动效真实能动：
1. **字体**（唯一指定两套，本地 woff2 自托管于 `assets/fonts/fonts.css`）：
   - 英文/数字 = JMH Typewriter（300/400/700/900，编号、日期、表格标签、标题大字全用它）
   - 中文 = 寒蝉活宋体 ChillHuoSong（400/700/800，统一 Regular 字面，禁用长体/宽体变体），复古活字铅印，撑得住大段攻略文字
2. **背景与纹理**：纸张纹理、胶片颗粒、halftone 网点、横线信纸、方格纸
3. **装饰素材（纯 CSS 描绘）**：回形针、印章/邮戳、邮票、活页打孔、撕纸边、标签贴纸、纸胶带、文件夹 Tab、条码、点阵/排线肌理块、虚线边界
4. **6 个组件逐个展示**：每个组件一个展示位 + 独立的交互/动效演示
5. **收纳组合演示**：组件散落桌面 → 收进 Folder 合拢成手册

### 交付物 3：Motion System 动效系统
把动效独立成一套有规范的系统，包含：
1. **动效原则**：物理纸张质感（折叠/展开/翻页/撕开）、"整理与整合"的仪式感、节奏与缓动规范（easing / duration 分级）
2. **组件级动效**（每个组件的进场 / 交互 / 退场 / 状态流转）：

| 组件 | 动效 |
|---|---|
| Clarify 澄清表 | 登记卡滑入桌面；勾选 = 手写笔迹描边；动态追问 = 卡片向下抽出新一栏；提交 = 盖章 + 回形针"咔"一下别到 Folder 封面 |
| Folder | 封面 3D 翻开像翻日记，夹着的卡片露出；往下翻时 POI 卡从夹页"挪出来"组成一天行程概览；反向收纳合拢 + 盖章；主动提问的探出效果 |
| POI 卡 + 交通路线 | 节点连线 SVG 描边生长（航线虚线 + 小船/小车沿路径走），卡片依次入场；玩法推荐拼贴展开/折叠 |
| Budget list | 便利贴粘在文档底部 → 点击"撕下"展开成独立收据（逐行打印吐出 + 金额滚动）→ Accept 后飞入方案合体 |
| Map | 十字折痕展开像真地图；POI 图钉逐个"啪"落下；行走小人光标（hover 变换动作）；智能 Zoom in/out 镜头动效；点景点纸张再展开（左地图右 POI 卡）；酒店图标 pop up |
| Flight list | 票根沿打孔线撕开的交互 |
| Packing list | 手绘笔迹划勾 / 删除线 SVG 描边 |
| 闪词提示 | 轻量便签从侧边弹出、抖动引起注意，确认后触发地图联动 |
| 通用 | 视差、打字机逐字揭示、scroll 触发入场；组件被 AI create 时"放上桌面"、remove 时"收走" |

3. **联动动效**：闪词确认 → 地图 pop up 酒店；预算 Accept → 合入 Folder；探索完成 → 全部收纳合拢

## 六、参考素材要点（来自灵感 folder 的图与视频）

- **视频**：档案夹 UI——外壳带侧边 Tab，内部叠放多层纸（衬线大标题档案纸、彩色摘录页、撕边黄色收据 + 回形针 + 印章），纸张可拖拽层叠，可缩放为双页平铺总览
- **票据**：复古票根版式（票号、日期格、座位格、虚线撕裂线、条码、双色印刷）
- **文件夹**：牛皮纸/马尼拉黄文件夹、Tab 标签、回形针夹照片、档案标签贴
- **地图**：奶油底柔和路网插画地图、带图例网格的交互地图 UI、POI 弹出卡
- **清单**：牛皮纸头便签本（编号 + 横线 + check 栏）、点阵打印行程表 + 手写涂鸦 + 邮戳
- **手绘设想图**：文件夹 Day1/2/3 Tab + 左页行程序列（POI 卡之间交通节点连接）+ 右页 budget list / packing list / interactive map；地图有折叠态和展开态（展开后 POI 详情弹出）
