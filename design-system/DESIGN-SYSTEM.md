# MorphUI Design System —「复古办公文具」工作台组件库规范

> **结论**：MorphUI 的所有组件都是"摆在办公桌上的复古文具"。壳用朴素牛皮纸色，内容物从城市分析图取 pastel 色；饱和色只做"笔迹"；万物皆有物理固定件；折叠态克制、展开态密集；动效全部是纸的物理行为（折、展、翻、撕、盖、别）。看完本文档 + `components.html` + `workspace.html`，你应当能独立做出风格一致的新组件。

---

## 1. 设计哲学（4 条原则）

### P1 · 组件即文具（Component as Stationery）
每个组件都必须能回答："它在真实办公桌上是哪件文具？"
- 旅行方案 = 马尼拉文件夹 · 预算 = 打印收据 · 机票 = 票根 · 行李 = 便签本 · 地图 = 折叠纸地图 · Clarify = 回形针别着的档案登记卡
- 找不到文具对应物的设计，不允许存在。

### P2 · 壳 + 探出的内容物（Shell & Peek）
主体永远是朴素的"壳"，内容物从边缘**探出一角**——露边暗示厚度和"可翻开"，绝不完全藏起，也绝不完全摊开。
- 折叠态：信息密度极低（一张铭牌标签 + 一个探出角）
- 展开态：才承载大量文字内容（组件必须装得下攻略正文）

### P3 · 万物皆有固定件（Everything Fastened）
任何附属元素都被**物理固定**：回形针、长尾夹、装订圈、纸胶带、打孔线、松紧带。**没有悬空漂浮的元素**——这是与现代 UI 最大的区别。叠放的纸永远不完全对齐（±1~3° 旋转 + 轻微偏移）。

### P4 · 动效 = 纸的物理行为（Paper Physics）
所有动效必须是纸在现实中做得出来的动作：折叠、展开、翻页、撕开、盖章、别上、抽出、滑入。禁止：淡入淡出打底、弹性果冻、发光、模糊变形。动效的终点永远是"被收纳/被固定"，制造"整理与整合"的仪式感。

## 2. 色彩体系

### 2.1 双层架构

| 层 | 谁 | 用什么色 |
|---|---|---|
| ① 壳层（不参与呼应） | Folder 外壳、桌面 | 牛皮纸/马尼拉中性色 |
| ② 内容层（与地图呼应） | 收据、票根、便签、POI 卡、登记卡、一切"笔迹" | 从 `assets/map-palette.jpg` 城市分析图取色 |

### 2.2 色板 Token

```css
/* 基底 */
--paper:   #F7F5F0;  /* 纸白：内页纸张底、大面积底色 */
--desk:    #EDEAE2;  /* 桌面灰米：workspace 背景 */
--kraft:   #D8CBB4;  /* 牛皮纸：便签头、包装 */
--manila:  #E8D9B0;  /* 马尼拉黄：Folder 外壳 */
--ink:     #3A4656;  /* 深灰蓝：正文与标题（禁纯黑） */

/* 分区 pastel（大面积色块用） */
--blue-baby:  #A9D3E5;  /* 水域、Day1 系 */
--green-mint: #CDE3CE;  /* 绿地、Day2 系 */
--pink:       #F5C6DE;  /* 贴纸、高亮、Day3 系 */
--coral:      #F0A87E;  /* 警示强调、餐饮 */
--lemon:      #F6EDA9;  /* 收据/便签/票根纸色 */
--lav:        #ABA6D4;  /* 次级点缀 */
--green-pine: #4E8F6E;  /* 深松绿：只做点阵肌理，禁大色块 */

/* 笔迹色（只做线/虚线/印章/描边，禁大色块） */
--cobalt:  #2B4EA8;  /* 路线描边、主要笔迹 */
--magenta: #D6338A;  /* 虚线边界、次要笔迹、印章 */
--gray:    #9C9C9C;  /* 细线路网、metadata 文字 */
```

### 2.3 使用规则

1. **大面积永远 = 纸白底 + pastel 色块**；饱和色（cobalt / magenta）只出现在线条、虚线、印章、路径描边这类"笔迹"上。
2. **跨组件色彩联动**：地图上 Day1 路线用婴儿蓝，则 Day1 的 POI 卡边、票根条、收据分区都用婴儿蓝系——色彩是跨组件的关联线索。
3. **禁止**：高饱和克莱因蓝大色块、现代扁平配色、纯黑 `#000`、渐变彩虹。

## 3. 字体体系

层级靠**切换字体族**而非字号爆炸。

| 角色 | 字体 | Fallback 链 |
|---|---|---|
| 英文标题（大字） | JMH Typewriter Black（900） | `'JMH Typewriter','Courier New', monospace` |
| 英文正文 / metadata | JMH Typewriter Regular（400，编号/日期/表格标签主力） | `'JMH Typewriter','Courier New', monospace` |
| 中文标题 | 寒蝉活宋体 ExBold/Bold（800/700） | `'ChillHuoSong','Songti SC', serif` |
| 中文正文 | 寒蝉活宋体 Regular（复古活字铅印） | `'ChillHuoSong','Songti SC', serif` |
| 中文情绪短句 / 窄排点缀 | 寒蝉活宋·长体 | `'ChillHuoSong Con','ChillHuoSong', serif` |

> 字体全部本地自托管（`assets/fonts/fonts.css`，woff2 子集），无外链依赖。中文层级靠**字重**（400/700/800）+ 长体切换，英文靠字重 300/400/700/900。JMH Typewriter 为 Personal Use Only 授权，仅限 demo。

字号只有 5 档：`12 / 14 / 16 / 22 / 34px`。metadata 永远 12px 打字机体 + `--gray` 或 `--ink` 70% 透明度。

## 4. 间距、层级与结构规范

### 4.1 间距

以 **8px 为基础网格**，但纸品允许"不齐"：
- 卡片内边距：`16px`（紧凑）/ `24px`（标准）
- 纸与纸的叠放偏移：`4~12px` + 旋转 `±1~3°`（用 `--tilt` 自定义属性随机取 `-3deg ~ 3deg`）
- 组件之间在桌面上的间隙：`≥ 24px`

### 4.2 阴影（纸的厚度，不是浮起）

```css
--shadow-paper: 0 1px 2px rgba(58,70,86,.10), 0 2px 6px rgba(58,70,86,.08);
--shadow-stack: 0 2px 4px rgba(58,70,86,.12), 0 6px 16px rgba(58,70,86,.10);
--shadow-lift:  0 8px 24px rgba(58,70,86,.16);  /* 仅拖拽中 */
```
禁止大范围柔光阴影（会显得"浮"而不是"叠"）。

### 4.3 z 序（桌面堆叠逻辑）

`桌面(0) < Folder 壳(1) < 内页纸张(2~5) < 附属小 file(6) < 拖拽中的组件(99) < 闪词提示(100)`

### 4.4 结构 DNA（每个组件必备）

1. **铭牌标签**：封面上一张小标签说明身份（组件标题区）
2. **Tab 标签** = 导航语言（Day1/2/3 等分类）
3. **打字机 metadata** 散布角落：`No. 0009 / ARCHIVE 08 / FILE #02 / EST. 2026`
4. **固定件** ≥ 1 个：回形针 / 胶带 / 打孔 / 装订线
5. **做旧点缀**：颗粒、印章、撕边——点缀不铺满

## 5. 肌理与装饰（全部 CSS 描绘）

| 肌理 | 实现 | 用在哪 |
|---|---|---|
| halftone 点阵 | `radial-gradient` 重复网点 | 绿地、色块填充（松绿点阵） |
| hatching 排线 | `repeating-linear-gradient` 45° 细线 | 区块底纹、强调区 |
| 方格纸 | 双向 `linear-gradient` 1px 线 | Clarify 卡、笔记区 |
| 横线信纸 | 水平 `repeating-linear-gradient` | Packing list、正文区 |
| 纸张颗粒 | SVG `feTurbulence` data-URI 叠加 | 全局桌面与纸面 |
| 虚线边界 | `dashed` 描边（magenta/cobalt） | 地图边界、裁切线 |

装饰件（纯 CSS）：回形针、印章/邮戳、邮票齿孔、活页打孔、撕纸边（`clip-path` 锯齿）、标签贴纸、纸胶带（半透明 + 轻微旋转）、文件夹 Tab、条码、票根打孔线。

## 6. 动效规范（Motion System 摘要）

### 6.1 缓动与时长分级

```js
EASE = {
  paper:  'power2.out',        // 纸张滑入/落下
  fold:   'power3.inOut',      // 折叠/展开（3D 翻转）
  stamp:  'back.out(3)',       // 盖章、图钉落下
  draw:   'none|power1.inOut', // SVG 描边生长
}
DURATION = { micro: .18, action: .35, fold: .6, scene: .9 }  // 秒
```

- 入场统一 stagger `0.06~0.1s`
- 3D 翻折 `perspective: 1200px`，transform-origin 在折痕处
- 描边生长用 `stroke-dashoffset`

### 6.2 组件动效速查

| 组件 | 进场 | 交互 | 状态流转/退场 |
|---|---|---|---|
| Clarify | 登记卡滑入桌面 | 勾选=手写笔迹描边；追问=向下抽出新栏 | 提交=盖章 + 回形针"咔"别到 Folder |
| Folder | 放上桌面 | 封面 3D 翻开；POI 卡从夹页挪出 | 反向收纳合拢 + 盖章 |
| POI+路线 | 卡片依次入场 | 航线虚线描边生长、小车沿路径走 | 玩法拼贴展开/折叠 |
| Budget | 便利贴粘在文档底部 | 点击"撕下"→逐行打印吐出+金额滚动 | Accept 飞入方案合体 |
| Map | 十字折痕展开 | 图钉"啪"落下；行走小人光标；智能 Zoom | 点景点纸张再展开（左图右卡） |
| Flight | 票根叠入 | 沿打孔线撕开 | 选中票留下，其余收走 |
| Packing | 便签滑入 | 手绘划勾/删除线描边 | — |
| 闪词 | 侧边弹出+抖动 | 确认→触发地图联动 | 滑出 |

## 7. Dos & Don'ts

### Do
- ✅ 每个元素先问"它是哪件文具、被什么固定"
- ✅ 叠纸带 ±1~3° 旋转和偏移
- ✅ 饱和色只画线、只盖章
- ✅ 折叠态克制（一张标签+一个探出角），展开态才密集
- ✅ 字体层级靠字重与字体族切换（活宋标题 vs 打字机 metadata）
- ✅ 动效是纸做得出来的动作，终点是"被收纳"
- ✅ metadata 小字散布角落（No. / ARCHIVE / DATE）

### Don't
- ❌ 悬空漂浮的元素（无固定件）
- ❌ 高饱和大色块、克莱因蓝、纯黑
- ❌ 现代扁平风：大圆角、发光、毛玻璃、渐变按钮
- ❌ 淡入淡出打底的动效、果冻弹跳、模糊变形
- ❌ 折叠态就把内容摊开（破坏密度反差）
- ❌ 做旧铺满（颗粒/印章是点缀，不是滤镜）
- ❌ 字号爆炸做层级（>5 档字号）
- ❌ 海洋风元素（贝壳、海浪）——主题是办公文具
