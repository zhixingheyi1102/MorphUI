The Desk — where components live

SEC. 02

桌面规范Desk Rules

项规范
桌面底色--desk #EDEAE2 + 26px 点网格 + 全局纸张颗粒（fixed 叠加，opacity .5）
组件间距≥ 24px；新组件放上桌面时优先落在空白区，允许轻微压角（≤ 12px）制造堆叠感
初始姿态每个组件带 ±1~3° 随机旋转（--tilt），拖拽开始时转正为 0°，落下时回到 tilt
z 序桌面(0) < Folder 壳(1) < 内页纸(2~5) < 附属小 file(6) < 拖拽中(99) < 闪词(100)
阴影静置 --shadow-paper；堆叠 --shadow-stack；仅拖拽中允许 --shadow-lift（8/24px）
关闭按钮不用现代 ✕ 圆钮——用品红笔迹小叉，位于组件右上角，hover 时画圈（描边动效）
滚动条细条 6px，颜色 rgba(ink,.25)，轨道透明——像纸边不像控件
空桌面态只留一枚居中铭牌标签："THE DESK IS CLEAR · 说点什么，放件文具上来"
SEC. 03

组件生命周期Lifecycle

AI 驱动的 create / update / remove 必须对应"放上桌面 / 换页盖印 / 收走"三种纸的动作。

事件动效（GSAP）时长/缓动
CREATE 放上桌面从桌面上方 40px 落下 + 旋转从 ±6° 回到 tilt，落地时阴影从 lift 收到 paper（"放下"感）0.55s · power2.out
UPDATE 内容更新纸面轻抖 1 次 + 更新区域用品红下划线描边扫过；如换 Day 页 = 翻页动作0.35s · power1.inOut
REMOVE 收走被提起（scale 1.03 + lift 阴影）→ 滑向 Folder 或桌面右缘 → 缩小消失0.5s · power3.in
DRAG 拖拽提起转正、lift 阴影；释放时 snap 网格 + 回 tilt，落点"啪"一下（scale .98→1）提起 0.18s / 落下 0.3s
FOCUS 对话提及对应组件回形针轻晃 + 铭牌标签高亮柠檬黄 1.2s（对话 ↔ 桌面的指向关系）0.8s · sine.inOut
联动闪词确认→地图酒店 pop up；Budget Accept→飞入 Folder；探索完成→全部收纳合拢+盖章见 Motion System
SEC. 04

对话栏Chat Rail

对话栏是"打字机纸带"：AI 消息 = 钴蓝虚线框 + 打字机逐字揭示；用户消息 = 柠檬黄纸片右对齐。组件产生时，在对话流里留一行存根（stub）——点击存根，桌面上的组件晃动示意位置。

AI 虚线框 · 打字机体 · 逐字揭示（12ms/字） USER 柠檬黄纸片 · 右对齐 · 轻微 tilt STUB "✦ 已放上桌面：地图" · 可点击定位 输入框 底部横线信纸样式，无圆角无发光
SEC. 05

工作台 Dos & Don'ts

Do ✓
  • 桌面永远保持"纸放在桌上"的隐喻：落下、提起、收走
  • 新组件入场后 2s 内不再有其他动效（一次只做一件事）
  • 对话与桌面互相指向（stub 点击 / FOCUS 晃动）
  • 组件密集时允许压角堆叠，但铭牌标签必须可见
Don't ✗
  • 网格化卡片流布局（那是 dashboard，不是桌面）
  • 组件淡入淡出出现（必须"放上/收走"）
  • 现代控件语言：圆角浮窗、毛玻璃侧栏、悬浮 FAB
  • 同屏超过 2 个组件同时做动效
